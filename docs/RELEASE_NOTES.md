# AgentKanban 0.8.1

- 桌宠终端外观：桌宠根据 Agent 上报的名字认出 Claude Code、Codex、Cursor、Gemini CLI 和 DeepSeek，穿上对应终端的配色并带一个像素标志；其他名字会得到固定的配色和标志。设置 → 桌面 → 桌宠 → 外观可以改为「主题色，只加标志」。
- 更省 CPU：看板上的「推进中」动效改为低帧率节拍，并且只用合成层能直接处理的属性，不再跟着显示器刷新率（如 144/170Hz）逐帧重绘，看板隐藏在托盘时也一样。桌宠按状态以 4/8/12 帧绘制，窗口隐藏时停止；重力模式下没有走动时循环会放慢，走路时窗口只在画面真正变化时移动。实测空闲时整体 CPU 占用约降到原来的四成。
- 更省空间：WebView 的 HTTP 缓存上限设为 4 MB。
- 桌宠窗口较窄时，悬停气泡不再超出窗口被截断。

数据库 schema 没有变化，可以和 0.8.0 共用数据。MCP 仍是三个工具，同步规则没有变化，无需重新接入。
