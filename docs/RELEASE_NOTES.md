# AgentKanban 0.7.0

- 个人待办：新建时勾选「仅自己」，记下自己要做的事。可以选项目目录，也可以不选，不选时放进置顶的「我的待办」分组。分「待办 / 我在做 / 已完成」三种状态，右键或在详情里切换；「我在做」计入「进行中」。Agent 通过 MCP 完全看不到、也改不动这些待办，通知和工作摘要也不包含它们。
- 接入你的 Agent：首次打开时看板顶部显示引导卡片，列出本机检测到的客户端，一键全部接入；设置 → Agent 接入新增「接入全部」。配置无法自动合并的客户端会提示手动配置并直达对应片段。接入成功或看板出现真实 Agent 任务后卡片不再显示，也可以直接关闭。
- 待继续：进行中的任务超过设定时间（默认 24 小时）没有 Agent 上报时显示「待继续」，保持原来的颜色和静止动效，只在「全部」中显示，不计入「进行中」。设置里的阈值改名为「多久没上报算「待继续」」。
- 看板整理：项目下的任务左侧带序号；「已归档」收进「已完成」里，显示为一行浅色文字，不再和项目折叠栏混在一起；进行中但暂时没有上报的任务显示所选动效的静止状态。
- 动效：明暗切换时整页淡入淡出；窗口置顶按钮开启时高亮，点击有按下 / 拔起动效；所有面板右上角的「返回」改为 × 图标，悬停时转动。
- 修复：反复切换明暗后部分文字和按钮停在旧主题颜色；用鼠标点过按钮后，按 Shift（如切换输入法）会出现焦点框。

数据库 schema 升到 6，首次启动自动迁移，迁移后旧版本无法再打开这份数据。MCP 仍是三个工具，同步规则没有变化，无需重新接入；升级后请重启正在运行的 Agent 会话，让它们加载新的 MCP 程序。
