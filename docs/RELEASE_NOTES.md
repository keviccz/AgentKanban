# AgentKanban 0.6.0

- 完成即变灰：Agent 报告完成后任务直接变灰并标记「未验收」，不再计入「等你处理」，也不弹通知；验收变为可选。右键任务可「一键验收」或「直接归档」，操作后几秒内可撤销。
- 项目操作：右键项目标题可设置颜色标签、重命名（只改显示名）、归档整个项目，或屏蔽项目——屏蔽后该项目从看板隐藏，之后在其中工作的 Agent 调用看板工具会被告知已屏蔽、不读不写；可在设置 → Agent 接入中取消。每个项目底部新增「已归档」分组，可就地恢复。
- Agent 推进提示：进行中且最近有上报的任务显示「推进中」动效，项目标题和窄条同步标记。提供呼吸光点、旋转光环、跳动三点、心电波形、文字流光、卡片左侧流光、卡片呼吸七种样式和 10 / 30 / 60 分钟判定时长。
- 外观：可选跟随系统 / 浅色 / 深色主题和 8 种主题色；新增中文 / English 界面切换，托盘菜单和系统通知一并切换。
- 使用：看板支持键盘操作（↑↓ 选择、Enter 打开、A 验收、E 归档、/ 搜索）；新增刷新按钮、工作摘要（今天 / 近 7 天 / 近 30 天，可复制为 Markdown）、可选的「Agent 完成任务时通知」和项目排序（最近更新 / 名称）。新建任务可从已有项目中选择，或通过「浏览…」打开文件夹选择窗口。
- 整理：自动归档同时覆盖未验收的已完成任务，每个项目最多保留最近 5 条已完成任务。
- 安装程序：采用应用配色和图标，按 Windows 语言显示中文或英文；手动输入的安装目录会自动补上 AgentKanban 子文件夹，卸载时不再弹出语言选择。
- 修复：双击标题栏后窗口无法拖动；关闭设置后「设置」按钮残留焦点框。

MCP 仍是三个工具，数据库 schema 保持 5，从 0.5 升级无需迁移。升级后请重新「一键接入」，让客户端加载新的同步规则（新增屏蔽项目的处理说明）。
