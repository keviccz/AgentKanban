# AgentKanban 0.5.0

- 应用内更新：在设置 → 软件更新中检查 GitHub Releases、查看版本说明并下载更新。默认每天自动检查，可选择自动后台下载；安装前验证签名、检查 MCP 占用并备份数据库。
- 同步健康：设置 → Agent 接入显示本机最近一次 MCP / CLI 调用、成功调用和成功保存时间，区分暂停与失败，方便核对断线后的补报情况。
- 归档中心：从设置打开归档任务，搜索、分页查看并恢复原任务，保留原有状态、验收结果、反馈和上报记录。
- 检索与最近变更：在看板中搜索项目和任务内容，按最近变更查找新进展、待验收与退回修改的任务。

MCP 仍保持三个工具；这些桌面功能不会增加 Agent 的工具调用或上下文。同步健康只反映本机处理记录，不代表客户端此刻在线，也不能证明尚未送达的进度已保存。

从 0.4 升级首次需要安装本版安装包，并让客户端重新加载 MCP。使用原有本地数据目录，数据库 schema 保持 5；旧版应用不具备本版的更新入口。
