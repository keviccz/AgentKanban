# AgentKanban 0.8.0

- 像素桌宠：每个 Agent 客户端一个像素小人（最多 3 个，最需要你处理的排在前面），站在看板顶边，把任务状态演出来。推进中推着写有步骤数的箱子，完成一步箱子闪一下；受阻或需要你补充时屏幕上是琥珀色「?」并挥手；完成待验收亮绿勾，验收时跳起来；新任务登记时把卡片抛上去；没有任务或记录已暂停时变灰打瞌睡。
- 拖动与吸附：桌宠默认吸附在看板顶边，看板移动或缩放时一起移动；拖到桌面任意位置会停在那里，重启后仍在原处；拖回看板顶边附近松手自动吸附。悬停显示状态和任务名，点击唤出看板并打开对应任务。
- 右键菜单：拆分 Agent（每个 Agent 一个独立窗口，可分别拖动，再点一次合回一排）、固定位置（不能拖动）、置顶（默认开启）、重力模式（落到任务栏上随机走动；出现新的「需要你补充 / 受阻」或完成待验收时，飞回看板顶边约 8 秒再落下）、吸附回看板、打开看板。每项都有对应的小动效。
- 设置 → 桌面 → 桌宠：可以关闭桌宠、改为始终只显示一个，或一键吸附回看板。

桌宠窗口透明的部分不会穿透点击，窗口宽度随 Agent 数量变化以减少遮挡；不需要时可在设置中关闭。数据库 schema 没有变化，可以和 0.7.0 共用数据。MCP 仍是三个工具，同步规则没有变化，无需重新接入；升级后请重启正在运行的 Agent 会话，让它们加载新的 MCP 程序。
