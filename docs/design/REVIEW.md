# 浮窗视觉核对

参考：[widget-concept.png](widget-concept.png)。使用内置 Image Gen 生成，主提示为「380×520 的 Windows 单列项目任务浮窗，白色/石墨深色两主题，细分隔线，克制状态色，顶部四个窗口按钮，四个状态筛选，项目三条预览、完成区折叠、底部本地保存说明，另含 380×48 窄条」。没有把参考图当成界面图片使用，文字与控件均由 React/CSS/SVG 绘制。

内置 IAB 返回 `Browser is not available: iab`。改用 Playwright 检查浏览器预览，并通过本地 CDP 连接真实 Tauri WebView，操作实际 SQLite 看板。Windows Computer Use 在初始化、重试和重置后均返回 native pipe unavailable，因此没有用浏览器截图冒充托盘点击证据。

已用 `view_image` 直接检查概念图和实际浅/深色截图。真实窗口为约 380×520 CSS 像素，系统缩放 125%；另检查 320×360、380×520、480×640，并通过 CDP 模拟 100%/125%/150% 显示密度。

| 比较点 | 结果与处理 |
| --- | --- |
| 布局 | 保留单列项目、三条预览、内容滚动、固定顶栏与页脚；没有堆叠卡片框 |
| 字体 | Segoe UI / Microsoft YaHei UI；CDP 确认实际字体，标题/进展/元信息分级 |
| 色彩 | 浅色白底、深色石墨背景；进行中青色、受阻琥珀色、待办灰色，完成绿色 |
| 控件 | 置顶、主题、窄条、隐藏图标与筛选均能操作；修正了最初不清晰的置顶图标 |
| 分隔与间距 | 项目及任务采用细线，正文换行、分支截断、时间保持可读 |
| 长内容 | 长中文及连续英文标题不溢出；状态始终可见，完整标题/进展可悬停查看 |
| 文案 | 概念中的品牌、筛选、任务字段、展开/完成区和页脚文案保留。任务内容、计数、时间来自隔离测试的真实 MCP 记录 |

明确差异：生成图的主体纵向比例偏长，实际遵循用户指定的约 380×520，把下方项目放入滚动区域。状态靠右对齐，给长标题留下稳定的换行空间；参考图的绝对时间示例替换为服务器时间派生的相对时间。空态、同步错误提示是功能所需状态。没有尚待修复的已观察裁切或横向溢出。
